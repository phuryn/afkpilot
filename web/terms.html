The service

AFK Pilot is a relay and web client that lets you control coding agents — Grok, Codex, and Claude Code — from a browser: agents running in your own editor through the Grok Build for VS Code (Community) extension, in Grok Build Desktop, or on an optional hosted cloud machine. You link a device with a one-time code (a cloud machine links itself), and messages are relayed between that device and your browser. We provide the connection and, where you enable it, the hosted machine; the agents, their subscriptions, and your workspace remain yours. The agents are products of their respective owners; AFK Pilot is an independent product.
