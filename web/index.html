    Using it

    What can I do from the browser?

    Nearly everything the sidebar does. The browser client is the host's chat UI — same layout, same controls — pointed at your machine instead of a local panel. What stays behind is whatever needs the host's local UI, whether that host is VS Code or Grok Build Desktop.

    From any browser

    • Send prompts and steer a run mid-turn
    • Dictate with your voice, then say “grok send”
    • Approve file writes, commands and plans
    • Stop, queue and fork a turn
    • Switch model, mode and thinking effort
    • Choose which repository each tab works in
    • See every project and its recent conversations side by side, and start one in any of them without switching first
    • Pick up the conversation open in VS Code or Desktop — both stay live
    • Browse the project's files in the same panel the desktop app has — several open at once; on a wide screen it sits beside the chat, on a phone it takes the whole screen
    • Open, edit and save a text file, syntax-highlighted while you read it and while you type
    • Follow a link in a README straight to the file it points at
    • Attach workspace files with @, add photos and documents
    • Export the conversation as a Markdown file
    • See what was attached — photos preview as thumbnails, and tapping one opens it full size
    • Have replies read aloud, shortened for listening if you want
    • Browse, resume, rename and delete past conversations — including the one you have open
    • Archive projects you are done with; anything quiet for a month files itself, and working in one brings it back

    Only at the desk

    • Dragging a file onto the composer
    • Adding a project folder — that opens a file picker on the machine itself
    • Connecting or signing out of an agent account — Grok, Codex and Claude Code all sign in through their own CLI on the machine, so the browser shows you which are connected but cannot change it
    • Linking a new machine — that starts in the extension or Desktop app
    • Video — images cross the wire, video never does
    • Photos attached before you installed this version — their previews were not kept
    Does it work with Codex and Claude Code?

    Yes — both. Grok Build — the VS Code extension and the desktop app — connects OpenAI Codex and Claude Code alongside Grok. Models from every connected agent appear in one picker, and each conversation keeps the agent it started with, so you can run all three side by side. Connect or sign out in Settings → Providers; if the Codex CLI isn't installed, the app offers to install it for you.

    From the browser, AFK Pilot shows which agents are connected and drives conversations on any of them. Signing in and out stays at the desk, since each agent authenticates through its own CLI on that machine.

    Do I need to leave my computer on?

    Yes. The agent runs on your machine, in either Grok Build for VS Code (Community) or Grok Build Desktop (Community), with your own model access — AFK Pilot is only the wire between it and your browser. Leave the host running and the workspace linked.

    In VS Code, you do not have to leave the Grok panel open, but you do have to open it once after you start VS Code: that is what dials the connection. In Desktop, open the app and link it from its AFK Pilot controls. After that, the local panel can be out of the way while the link stays up.

    While a device is linked, the extension holds your operating system's own wake lock so the machine will not idle-sleep and drop the connection while you are away. Your screen still goes dark, and grok.remote.keepAwake turns the whole thing off. If the machine does go down, the device simply shows as offline and reconnects by itself when it comes back.

    Is my phone one of my linked devices?

    No. A linked device is a machine running a host — VS Code or Grok Build Desktop — and that is what the Free plan's one-device limit counts. Running both hosts on the same computer still counts as one device. Open the browser client on as many phones, tablets and laptops as you like; they all reach the same workspace, and two of them can watch the same run at once.

    Your data

    Do you store my prompts or my code?

    No. Prompts, replies, file contents and images pass through the relay in memory and are dropped. There is no chat history on our servers because there is no chat log on our servers — your sessions live on your own machine, the same as they did before.

    What we do keep is the minimum to run an account: your sign-in identity, a device name and key identifier, and, on the Free plan, a single number — how many messages you have sent this week. The privacy policy lists all of it.

    Is it end-to-end encrypted?

    Both hops are encrypted: browser to relay, and relay to your machine, each over TLS. Nothing crosses the network in the clear.

    It is still not end-to-end, and we would rather say so than imply otherwise: the relay terminates both hops to route between them, so a message is briefly in plaintext in its memory as it passes through. Nothing is written down — prompts and code are never stored, on the relay or in its database.

    What the relay cannot do is act on your editor. It is policy-free by design: the gate deciding which messages may touch your machine lives in the extension, on your machine. Even a compromised relay cannot make your host open a file, run a picker, or change your settings.

    Apps

    Is there an iOS or Android app?

    Not yet. Install this site instead — it is built to work as one. On Android, Chrome or Edge, sign in and use the Install app button in the header; on an iPhone or iPad, tap Share, then Add to Home Screen.

    You get an icon on your home screen, a full-screen window with no browser chrome, and a session that stays signed in. It also updates itself, so a fix reaches your phone the moment we ship it, with no store review in between.

    Plans

    Do I have to pay to use the extension or the desktop app?

    No. Both hosts are free and their messages are never limited — the Grok Build for VS Code (Community) extension in VS Code, Cursor, Antigravity or any other editor it supports, and Grok Build Desktop (Community) on Windows and macOS. Stay at your keyboard and there is nothing to pay and nothing to count.

    What AFK Pilot's Free plan meters is remote messages: the ones you send from your phone or another browser to steer that same agent while you're away from the desk. That's 100 a week on 1 linked device — Remote Max removes the limit.

    What happens when I hit the free limit?

    Sending from the browser pauses until your weekly window resets, and the usage meter shows the countdown once you pass 80%. Nothing is lost — the agent, your sessions and VS Code carry on exactly as normal at the desk. The one-device limit works the same way: link a second machine and you will be asked to upgrade rather than cut off.

    How does payment work, and can I get an invoice?

    Checkout runs through Stripe. We never see or store your card details, and starting on Free never asks for a card at all.

    Every payment gets a receipt by email. If you need a proper VAT invoice, write to support@productcompass.pm and we will issue one.

    How do I cancel?

    From your account page, any time, in one click. Access runs to the end of the period you have paid for and then drops back to Free — your linked devices and your sessions stay where they are.

    Help

    Something is broken. Where do I report it?

    Report a bug or request a feature on the extension's GitHub repo. Bugs and feature requests for both the extension and this remote client go there, in the open, where other people can find the answer too.

    For anything about your account, billing or privacy, email support@productcompass.pm.
