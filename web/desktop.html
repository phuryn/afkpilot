Grok Build (Community) — standalone host

The agents, outside the editor.

Grok Build Desktop (Community) is a free, unofficial Electron app for working with Grok, Codex and Claude Code without terminal or IDE (e.g., VS Code) — the original harnesses, with your own subscriptions. Open your projects, work with your agents, and keep the same host close at hand when you do not need an editor.

Free to use · macOS and Windows · bring your own subscriptions

Rather install nothing at all? A Cloud machine runs Grok, Codex and Claude Code on a dedicated VM you reach from a browser, and all three sign in from the browser too — included with an AFK Pilot subscription while it is in preview.

A second way to host

Desktop is the host. AFK Pilot is the link.

Use the standalone app when you want the agents without an IDE. Add AFK Pilot to pick up the same work from a phone or browser — or skip local installs entirely with a Cloud machine, a separate hosted environment where Grok, Codex and Claude Code come preinstalled and connect from the browser.

On macOS, the app is signed with a Developer ID and notarised by Apple. It opens on first launch — no warning to dismiss, nothing to allow through in Settings.

On Windows, the installer is not code-signed yet, so SmartScreen shows “Windows protected your PC” the first time: click More info, then Run anyway. A certificate is on the way.

The app runs coding agents on your machine. It reads and edits files and runs commands, asking you first unless you turn that off — the same as the VS Code extension. Open projects you trust, and read the source if you want to see exactly what it does.
